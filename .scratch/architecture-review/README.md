# Architecture review

This folder holds the one-shot brief for an external high-capability
model: evaluate the generator and LLM call structure, then emit a prompt
the next coding agent can use to map the rewrite.

**Use:** open `EVALUATION-PROMPT.md`, copy everything below the first
horizontal rule, paste it into a model that can read this repo. Do not
ask that model to implement. Its Part B output is the next agent's
input.

The product owner was not available for a live Q&A. Locked assumptions
are listed in section 2 of the prompt. If any of those is wrong, correct
them in the pasted brief before running it.
